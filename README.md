# module-dashboard

Dashboards: pages of cards that the installed modules offer, such as the time, what is coming up,
a picture of the day, a device's readings or a todo list, arranged by whoever makes one, shown full
screen on a wall, and shown on screens that never sign in through a display link.

An [EiN](https://github.com/einhq) module. It is developed and tested inside a checkout of EiN core,
as `modules/dashboard`, and a deployment chooses whether to run it.
